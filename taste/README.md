# Taste Taste Pack

This directory is the product's one Taste Pack. Read `skills/product-design/SKILL.md`, then Decisions under `skills/product-design/references/decisions/`.

Conformance and Expression are derived activities, not folders. A Decision is Conformance only when it is accepted, includes matching host-reported validation and user-approval evidence, has shipped evidence, and has no coverage gap. During Expression, the host keeps draft feedback and iterations in its active task. Taste records only the final artifact and Decision the host reports as tested and user-approved. The starter is not product knowledge.
