# Example Product design

This example is synthetic. Its conventions demonstrate organization only; they are not reusable prescriptions.

## Choose a mode

- Use **Conformance** when the user asks for a change consistent with the established product direction and there is sufficient accepted evidence.
- Use **Expression** when the user asks to explore or establish a new direction.
- If a request mixes both or evidence cannot resolve a consequential choice, ask the user. Follow explicit intent and explain conflicts with accepted guidance.
- When the user accepts an Expression direction, record that decision and use it as Conformance evidence in later work.

Read shared product facts, then only the relevant mode references. Treat shipped work as evidence, not as an automatic rule; note known flaws and uncertainty.
