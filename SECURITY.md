# Security Policy

## Supported Versions

Security fixes are applied to the default branch. The only published line today is `0.1.x`.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately.

Use GitHub private vulnerability reporting:

https://github.com/gksoriginals/taste/security/advisories/new

A maintainer has to enable private vulnerability reporting before that form accepts reports. There is no dedicated security email yet. If the form is unavailable, open a GitHub issue that asks for a security contact. Do not include exploit details, proofs of concept, or credentials in a public issue.

Tell us the affected version, how to reproduce the issue, and the impact you expect. We will acknowledge a report when we see it and will follow up after we can confirm or decline it. Please give us a chance to investigate before any public disclosure.
